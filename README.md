# TheCuratist

TheCuratist is an aesthetic moodboard studio designed to help users visually curate ideas through an intuitive and minimal interface.

##  Features
- Interactive moodboard with visual cards
- Clean, UI
- Responsive layout for different screen sizes
- Intro popup overlay for immersive onboarding
- Designed for future drag-and-drop and real-time collaboration

##  Tech Stack
- HTML
- CSS
- JavaScript
- Firebase (planned)

##  Status
This project is under active development. Features and UI are being iterated continuously.
